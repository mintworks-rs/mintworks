# Security policy

## Reporting a vulnerability

Please report privately, never in a public issue:

- by email to **szilu@symbion.hu**, or
- through GitHub's private vulnerability reporting on this repository.

Include what is affected, how to reproduce it and what an attacker gains.

Symbion Mintworks has a single maintainer, so handling is best effort. You will get an
acknowledgement within **7 days**, and we will agree on a disclosure date once a fix is in sight.

## Supported versions

Only the latest 0.x release receives security fixes.
